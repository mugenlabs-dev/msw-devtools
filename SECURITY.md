# Security policy

## Supported versions

Only the latest minor release of `@mugenlabs/msw-devtools` receives fixes. The package is pre-1.0, so upgrade to the newest version before reporting.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/mugenlabs-dev/msw-devtools/security/advisories/new) instead.

Include the affected version, how to reproduce it, and the impact you expect. You should get a reply within a week. Once a fix is released, the advisory is published with credit to you unless you'd rather stay anonymous.

## Scope

The package is a development tool: it runs in the browser next to Mock Service Worker and should never ship to production. Reports about the published package, the demo site at msw-devtools.mugenlabs.dev, and this repository's CI are all in scope.
